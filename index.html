你可能想知道。

关于使用、更新，以及你的数据。

需要准备 API 密钥吗？

使用云端服务时通常需要。首次使用时，在“设置 → AI 配置”中选择服务提供商、填写服务地址与密钥，再点击“应用连接”并选择模型。支持 Anthropic、OpenAI、Gemini 及兼容网关；Ollama 和允许匿名访问的自定义网关可不填密钥。应用不提供内置 API 额度；API 服务可能按其规则收费。

我的文字会发到哪里？

你选中、输入或粘贴并提交的文字，会发送到你配置的 AI API，用于生成解释和卡片。请先了解该服务的数据政策，不要提交无权发送的敏感内容。

学习记录默认保存在本机；本地学习数据文件不是加密文件，已保存的密钥由 Windows DPAPI 加密。日志可能含原文片段和窗口标题。安装版还会连接 GitHub 检查应用更新。

支持哪些系统和应用？

当前提供 Windows x64 桌面版本，不是浏览器扩展。快捷键取词依赖 Windows 的复制操作，适用于能正常复制所选文字的应用；受保护内容或特殊控件可能无法取词。遇到这种情况，可以在应用中直接输入或粘贴。

安装版与便携版，应该选哪个？

日常使用建议选择安装版。安装版支持检查更新、后台下载，并在退出应用后安装已下载的更新；在“设置 → 关于”中可以查看状态或手动检查。

便携版可直接运行，但不支持自动更新，需要从 GitHub Releases 手动下载新版本。开发版本也不支持自动更新。请以发布页的文件说明为准。

GitHub 同步是必须的吗？会同步什么？

不是。同步默认关闭，单机使用不需要 GitHub 令牌。需要跨设备同步时，请使用你自己已初始化的私有仓库，以及仅授权该仓库 Contents 读写权限的细粒度个人访问令牌。这个仓库与你正在访问的产品公开代码仓库不同。

启用后，完整原文、解释、卡片、复习状态、语言组合与熟练程度会写入 GitHub。API 密钥和访问令牌不会写入同步文件。仓库读者可看到这些学习数据，删除记录也不会清除旧的 Git 提交；之后公开仓库会暴露历史内容。

AI 的解释总是正确的吗？

不一定。解释与卡片由你配置的模型生成，可能出现错误，或遗漏特定语境。重要内容请结合原文、词典或其他可靠来源核对。
